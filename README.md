The repository contains three files. Each of them contains the Luanti/Minetest based prototypes of the three engineering 
buildings(SEB, TEB, ACEB) on the Western University campus.

Instructions:
1. Open Minetest
2. Click the 'About' tab
3. Click 'Open User Data Directory"
4. Open the 'Worlds' folder
5. Move the folders from this repo into the 'Worlds' folder
6. Navigate to 'Start Game' tab in Minetest
7. Play game!!!
